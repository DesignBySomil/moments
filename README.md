# moments

30 tiny seamless-loop HTML animations in a swipeable carousel, built for screen recording.

Open `index.html` (or the hosted URL). Swipe or use arrow keys to move between scenes. The UI chrome fades away after a moment so you can screen-record clean loops. `?clean` hides the chrome immediately, `#/<scene-id>` deep-links a scene.

Scenes: bloom, sail, bird, wave, cycle, rain, candle, campfire, moonsea, meteors, dandelion, leaves, snow, lighthouse, lantern, balloon, kite, paperplane, waves, jellyfish, butterfly, sunrise, train, windmill, pendulum, fireflies, aurora, umbrella, swing, sprout.

Pure HTML/CSS/JS, no dependencies, no build step.
